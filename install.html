How to install설치 방법

The free direct download, installed in a few clicks. 무료 직접 다운로드, 몇 번의 클릭으로 설치합니다.

  1. Extract the zip압축(zip)을 풉니다

    Unzip the downloaded OtterZip_x64_installer.zip into any folder.받은 OtterZip_x64_installer.zip을 아무 폴더에나 풉니다.

  2. Right-click Install.ps1 → Run with PowerShellInstall.ps1 우클릭 → PowerShell에서 실행

    Inside the extracted folder, right-click the Install.ps1 file and choose "Run with PowerShell".푼 폴더 안의 Install.ps1을 오른쪽 클릭하고 "PowerShell에서 실행"을 선택합니다.

  3. Click "Yes" on the prompt권한 창에서 "예"를 누릅니다

    A User Account Control (UAC) window appears. Click "Yes" — on the first install it registers the app's publisher certificate as trusted, one time.사용자 계정 컨트롤(UAC) 창이 뜨면 "예"를 누릅니다. 처음 설치할 때 앱 게시자 인증서를 신뢰 목록에 1회 등록합니다.

  4. Done — launch from Start끝 — 시작 메뉴에서 실행

    OtterZip is installed. Open it from the Start menu, or just right-click any file in Explorer.설치 완료. 시작 메뉴에서 열거나, 탐색기에서 파일을 우클릭하면 바로 쓸 수 있어요.

Why the certificate step? The direct download is signed by us (LumiBear Studio), not by the Microsoft Store. Windows asks you to trust our signature once — that is what the UAC prompt does. It is the exact same app as the Store version: no ads, no accounts, no tracking.인증서 단계가 왜 있나요? 직접 다운로드판은 Microsoft Store가 아니라 저희(LumiBear Studio)가 직접 서명합니다. Windows가 그 서명을 한 번 신뢰해달라고 묻는 것이 UAC 창입니다. 스토어 버전과 완전히 같은 앱이며 광고·계정·추적이 없습니다.
